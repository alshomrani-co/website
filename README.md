# موقع وتطبيق شركة سعد الشمراني للاستشارات الهندسية

ريبو واحد فيه الموقع، وبوابة الموظفين، ولوحة التحكم، والبصمة، وتقرير الإشراف. كلهم شغالين على نفس مشروع Firebase بتاع البصمة (`alshmorani-1a1a2`)، والموظف بيدخل بنفس اسم المستخدم وكلمة السر في كل الأقسام.

## محتويات الريبو

| المسار | إيه هو |
|---|---|
| `index.html` | الموقع للعملاء: الرئيسية بفيديو، الخدمات، الأعمال، الباقات، من نحن، الدعم الفني، اطلب خدمة، تتبع طلبك، تواصل |
| `portal.html` | بوابة الموظفين: دخول، تسجيل بكود دعوة، الأقسام، طلبات الدعم، أرشيف التقارير |
| `admin.html` | لوحة التحكم: كل نص وصورة ورقم في الموقع، الموظفين والصلاحيات، كود الدعوة، النسخ الاحتياطي |
| `basma/` | تطبيق البصمة كما هو (v38) |
| `report/` | تقرير الاستلام الهندسي (IR) بالشعار المتحرك + حفظ في الأرشيف |
| `config.js` | إعدادات Firebase ورقم المالك |
| `assets/` | التصميم والسكربتات والصور والفيديو |
| `firestore-additions.rules` | الإضافات اللي لازم تتضاف لقواعد Firestore |
| `.github/workflows/android.yml` | بناء تطبيق أندرويد واحد لكل حاجة |

## الدخول للموظفين

- العميل مش بيشوف أي زرار تسجيل دخول.
- للموظف: **اضغط ضغطة مطوّلة (حوالي ثانية ونص) على اللوجو** فوق في الموقع. هيظهر حلقة بتتملي، وبعدها تفتح بوابة الموظفين.
- الرابط المباشر كمان شغال: `.../portal.html`.

## خطوات الرفع (مرة واحدة)

1. اعمل ريبو جديد في `alfayz-co`، مثلاً باسم `alshomrani`.
2. ارفع **كل** الملفات والفولدرات زي ما هي، بما فيها `.github` و `.nojekyll`.
3. من **Settings → Pages**: اختار Branch `main` والفولدر `/ (root)`.
4. الموقع هيبقى على `https://alfayz-co.github.io/alshomrani/`.
5. في Firebase: **Authentication → Settings → Authorized domains**. لازم يكون فيها `alshomrani-co.github.io`، وده غالباً موجود من أيام البصمة.
6. في **Firestore → Rules**: الصق محتوى `firestore-additions.rules` جوه القواعد الحالية، بعد دوال `isOwner` و `isActiveEmp`، وبعدين **Publish**.
7. ادخل البوابة بحساب المالك، ومن **لوحة التحكم → الموظفين والصلاحيات** ولّد كود دعوة واحفظه.

## صلاحيات الموظفين

كل موظف بيتحدد له أقسام من لوحة التحكم:

- **البصمة**
- **تقرير الإشراف**: يعمل تقارير ويحفظها في الأرشيف.
- **أرشيف التقارير**: يشوف تقارير كل المهندسين.
- **الدعم الفني**: يرد على طلبات العملاء ويغيّر حالتها.
- **لوحة التحكم**: يعدّل محتوى الموقع.

المالك عنده كل حاجة. صفحة الموظفين نفسها للمالك بس.

موظفين البصمة الحاليين بيفضلوا شغالين عادي. أي موظف ملوش صلاحيات متحددة بيشوف البصمة بس، لحد ما تديله صلاحيات من لوحة التحكم.

## تعديل الموقع

- كل حاجة من `admin.html`: النصوص، الصور (بتترفع وتتضغط لوحدها)، الأرقام، الخدمات، المشاريع، الباقات، الفروع، الأسئلة، شريط الإعلان، نافذة العروض، وSEO.
- زرار **👁 معاينة** بيفتح الموقع وبيتحدث مباشرة وانت بتكتب، قبل النشر.
- **حفظ ونشر** (أو Ctrl+S) بينشر التعديل للكل فوراً.
- **فيديو الواجهة**: استبدل `assets/video/hero.mp4` بفيديو تاني، أو اكتب رابط mp4. الأفضل يكون 720p، من 8 لـ 12 ثانية، وأقل من 3MB.

## تطبيق الأندرويد

- من **Actions → Android APK → Run workflow**.
- ملف `shamrani-app.apk` هيطلع في **Releases**.
- التطبيق بيفتح الموقع، والموظف يدخل بالضغطة المطوّلة. البصمة والتقارير جوه نفس التطبيق.
- تطبيق البصمة القديم (`com.alshomrani.basma`) يفضل شغال لوحده لحد ما تقرر توقفه.

## عند أي تعديل

بستلم منك طلب التعديل وبسلّمك نسخة كاملة جديدة من الريبو. ارفعها كلها فوق القديمة.
