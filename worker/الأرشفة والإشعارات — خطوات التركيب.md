# الأرشفة لجوجل درايف + الإشعارات وهو مقفول — خطوات التركيب (مرة واحدة)

سكربت واحد على **إيميل الأرشيف** بيعمل الحاجتين:
- **الأرشفة:** بينقل ملفات الأقسام القديمة لدرايف: `أرشيف الشمراني / السنة / الشهر / القسم` (PDF مبسّط + JSON للاسترجاع).
- **الإشعارات:** بيبعت إشعار للموظفين (رسالة عميل، طلب خدمة جديد) وللعميل (رد المهندس) حتى والتطبيق مقفول.

مش محتاج خطة Blaze، ومفيش مفاتيح سرية: السكربت بيستخدم صلاحية الإيميل نفسه.

## 1) اعمل الإيميل عضو في مشروع Firebase
1. ادخل **console.firebase.google.com** بحساب المالك ← المشروع **alshmorani-1a1a2**.
2. ⚙ **Project settings** ← **Users and permissions** ← **Add member**.
3. اكتب إيميل الأرشيف، والدور **Editor** ← **Add member**.

## 2) مفتاح الإشعارات (VAPID)
1. في نفس الإعدادات: تبويب **Cloud Messaging** ← **Web Push certificates** ← **Generate key pair**.
2. انسخ المفتاح (بيبدأ بحرف B وطويل).
3. لوحة التحكم في الموقع ← **الإشعارات والصلاحيات** ← الزقه ← **حفظ**.
   (ده مفتاح عام ومش سري.)

## 3) السكربت
1. ادخل بإيميل الأرشيف على **script.google.com** ← **New project** ← سمّيه `الشمراني — أرشيف وإشعارات`.
2. امسح الكود اللي فيه ← الزق محتوى ملف `archive-push.gs` كله.
3. ⚙ **Project Settings**:
   - علّم على **Show "appsscript.json" manifest file**.
   - تحت **Google Cloud Platform (GCP) Project** اضغط **Change project** ← اكتب رقم المشروع **608129324316** ← **Set project**.
4. ارجع للـ Editor ← افتح `appsscript.json` ← امسح اللي فيه ← الزق محتوى ملف `appsscript.json`.
5. اختار الدالة **setup** من فوق ← **Run** ← وافق على الصلاحيات بنفس الإيميل.
6. لو ظهر «Google hasn't verified this app» ← **Advanced** ← **Go to … (unsafe)**. ده طبيعي لأنه سكربتك انت.

من الوقت ده السكربت بيشتغل لوحده كل دقيقة.

## 4) التأكد
- لوحة التحكم ← **مركز الأرشفة**: هيظهر «🟢 سكربت جوجل متوصّل».
- حط إيميلك في «إيميل تقرير الأرشفة» ← حفظ.
- **أول أرشفة بتبقى نسخ تجريبي بس** (من غير مسح من الموقع). بص على درايف، ولو تمام شغّل النقل الفعلي.

## الإشعارات على الموبايل
- **أندرويد / كمبيوتر:** افتح الموقع أو البوابة ← اسمح بالإشعارات من شاشة الترحيب أو صفحة **الصلاحيات**.
- **آيفون:** لازم iOS 16.4 أو أحدث، وتضيف الموقع للشاشة الرئيسية (مشاركة ⬆️ ← إضافة إلى الشاشة الرئيسية)، وتفتحه من الأيقونة وتسمح بالإشعارات.

## ملاحظات
- النقل بيمسح من الموقع **بعد** ما الملف يتحفظ في درايف. الاسترجاع من «سجل الأرشفة» بيرجّعه زي ما كان بالظبط.
- بيانات العملاء والموظفين والإعدادات ما بتتأرشفش.
- الحد المجاني لدرايف 15 جيجا. العداد في مركز الأرشفة بيوضح المستخدم.
- لو عايز توقف السكربت: script.google.com ← **Triggers** ← امسح التريجر.
